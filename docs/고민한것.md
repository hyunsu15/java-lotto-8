# 고민한 것

## 이번 미션에서 가장 오래 고민했던 부분과 시도들

### 설계

전에 했던 설계를 비슷하게 할지, 아니면 새로운 설계할지
우선 기존 설계를 어느정도 사용할 예정.

- 추상클래스로 탬플릿을 만들예정이다.
    - 전 요구사항은 추상화하기 애매했었다. 어떨때는 입력만 받고, 어쩔떄는 그냥 결과 값만 반환해야했었음.
    - 지금 요구사항은 로직들이 나름 일관되게, 입력값 검증,로직,출력 이기에 사용해도 될듯.

### 요구사항이상의 설계를할지

전에 만든 클라이언트,서버 같은경우 다른 클라이언트를 쓰면, 안되는 문제가 있었음.
하지만 너무 오버 엔지니어링같아서 살짝 애매한다.

우선 요구사항 이상 설계는 안하는걸로 정함.

이전요구사항을 할때 과하게 했었나 싶었다.

- 전 요구사항때는 클라이언트와 서버를 구별해서 나름 구현했었다. 이것을 이어주는 common 폴더도 만들었다.
- 지나고 보니, 해당 기능들이 과연 서버로까지 분리했어야하는 일인가 싶다.
