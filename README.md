# java-lotto-precourse

## 뭐하는 프로젝트임?

우아한테크코스 프리코스의 로또 프로그램을 구현한 내용임.

## 주요기능

- [x] 로또를 구매하는 기능
    - 개당 1천원
    - 1,000 단위가 아니면 다시 입력해야 함.
- [ ] 구매한 로또를 보여주는 기능
- [ ] 당첨된 로또번호를 입력하는 기능
    - 당첨 로또번호는 구별자가 ,이고 1부터 45이어야함.
        - 이렇게 조건에 맞지않으면, 다시 입력해야 함.
    - 구체적으로 당첨된 로또번호, 보너스 로또번호 입력해야 함.
- [ ] 당첨통계 보여주는 기능
- [ ] 수익률을 보여주는 기능
